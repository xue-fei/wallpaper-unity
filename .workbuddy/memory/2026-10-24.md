## SimpleWater.shader 从 Built-in 移植到 URP（粉红色修复）

**根因**：`Assets/SimpleLowPolyNature/Shaders/SimpleWater.shader` 原版是 Amplify Shader Editor 生成的 Built-in Surface Shader（`#pragma surface surf StandardSpecular` + `GrabPass{}` + `UnityCG.cginc`/`UnityStandardUtils.cginc`）。项目升级到 URP 后这些 include 与 GrabPass 全部失效 → 没有任何 Pass 被 URP 识别 → 回退内置 Error 着色器 → 粉红。

**改动**：整体重写为手写 HLSL，三个 Pass：
- `WaterForward`（LightMode=UniversalForward）：Core/Lighting/DeclareDepthTexture/DeclareOpaqueTexture 四个 include；CBUFFER(UnityPerMaterial) 一份；逐项移植 6 个特性（顶点波动、双法线 panner、深度差 pow+falloff、泡沫、屏幕折射、高光）。
- `ShadowCaster`（LightMode=ShadowCaster）：自写精简 Pass + `ApplyShadowBias` + `_LightDirection`/`_LightPosition` + `#pragma multi_compile_vertex _ _CASTING_PUNCTUAL_LIGHT_SHADOW`。**不能用** `ShadowCasterPass.hlsl`（内部依赖 `_BaseMap`/`_BaseColor`/`_Cutoff`，本 shader 无这些属性）。
- `DepthOnly`（LightMode=DepthOnly）：自写精简 Pass，供 URP 生成 `_CameraDepthTexture`。**不能用** `DepthOnlyPass.hlsl`（同样依赖 `_BaseMap`/`_Cutoff`）。
- `Fallback Off`；移除 `CustomEditor "ASEMaterialInspector"`（项目未装 Amplify Shader Editor）。

**移植时踩到的 4 个语义不等价点（已修正）**：
1. `ComputeNormalizedDeviceCoordinatesWithZ(positionCS)` **不能**用——该函数内部 `float4(position,1.0)` 丢弃 w，透视除法失效 → 屏幕 UV 全错。改用 URP 官方 `Shadows.hlsl:424` 同款 `ComputeScreenPos(positionCS)`（等价原版 `i.screenPos` / `tex2Dproj` 输入，含 `*0.5+o.w` 与 `UNITY_UV_STARTS_AT_TOP` 翻转）。
2. 折射扰动必须用**切线空间**法线 `normalTS.xy * _Distortion`（原版 `o.Normal` 即切线空间），不能换成世界空间法线（会整体漂移）。
3. 法线需乘 TBN 才是世界空间；水面网格是内置 `Plane`（fileID 10209）**无切线**（`tangentOS.w==0`），加回退分支（world X/Y 做副法线，等轴缩放下等价自动切线）。
4. 阴影接收：补 `#pragma multi_compile _ _MAIN_LIGHT_SHADOWS _MAIN_LIGHT_SHADOWS_CASCADE _MAIN_LIGHT_SHADOWS_SCREEN` 等，否则阴影区水面过曝发亮；输出乘 `mainLight.shadowAttenuation`。
5. 缺失 GPU instancing 关键字 → 补 `#pragma multi_compile_instancing`。

**URP Asset 同步修改**：`Assets/Settings/{Very Low,Low,Medium,High,Very High,Ultra}_PipelineAsset.asset` 全部 `m_RequireDepthTexture: 1` + `m_RequireOpaqueTexture: 1`（深度混合与屏幕折射的前提；不满足时不会粉红，但会渲染异常）。当前激活的是 Medium（QualitySettings `m_CurrentQuality: 2`，GraphicsSettings 指向 Medium 的 guid `f368c41ab0c5225459306a73615b1158`）。

**API 核对结论（URP 12.1.15 源码）**：`SampleSceneDepth/Color` ✅、`UnpackNormalScale`（core `Packing.hlsl:220`）✅、`_ZBufferParams`（`UnityInput.hlsl:76`）✅、`GetMainLight`（`RealtimeLights.hlsl:114`，Lighting.hlsl:7 引入）✅、`SampleSH`（`GlobalIllumination.hlsl:29`）✅、`ApplyShadowBias`（`Shadows.hlsl:430`）✅、`ComputeScreenPos`（`ShaderVariablesFunctions.deprecated.hlsl:9`，经 Core.hlsl:193 引入）✅、`unity_WorldTransformParams`（`UnityInput.hlsl:111`）✅。

**注意**：同文件多 Pass 各自 `CBUFFER_START(UnityPerMaterial)` 不会冲突（CBUFFER 是 CBuffer 语义，非变量声明），URP 官方 Lit.shader 多 Pass 均重复包含 `LitInput.hlsl`（内含同一 cbuffer）。
